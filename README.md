# NFI Market Intelligence Dashboard - GitHub Pages package

This package is prepared for a simple GitHub Pages deployment.

## Files included
- `index.html`
- `.nojekyll`
- `README.md`

## What is included in this version
- Single-file dashboard deployment
- Updated NFI login intro experience
- Cleaned-up login copy with internal/explanatory notes removed
- Featured emphasis remains in the animation visuals for Inland Empire, CA and Lehigh Valley, PA
- Same login credentials as prior version

## Deploy to GitHub Pages
1. Upload all files in this package to the root of the existing repository.
2. Commit the changes.
3. Wait a minute or two for GitHub Pages to publish.
4. Hard refresh the live site with Ctrl + Shift + R.
