# NFI Market Intelligence Dashboard - GitHub Pages package

This package is prepared for a simple GitHub Pages deployment.

## Files included
- `index.html`
- `.nojekyll`
- `README.md`

## What is included in this version
- Single-file dashboard deployment
- Updated NFI login intro experience
- Cleaner intro layout with improved text legibility
- Stronger left-side overlay and content panel to prevent text overlap
- Featured emphasis on Inland Empire, CA and Lehigh Valley, PA
- Same login credentials as prior version

## Deploy to GitHub Pages
1. Upload all files in this package to the root of the existing repository.
2. In GitHub, go to **Settings > Pages**.
3. Under **Build and deployment**, confirm:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
4. Save if needed.
5. Wait a minute or two for GitHub Pages to publish the updated site.
